# 🛡️ Fraud Detection & Transaction Analysis

## 📌 Project Overview

This project focuses on the analysis of financial transaction data to identify fraudulent activities and uncover transaction patterns using data analytics and visualization techniques. The analysis provides valuable insights into fraud-prone transaction types, transaction amount distributions, and business risks associated with financial fraud.

The project demonstrates practical applications of data science in the FinTech industry by leveraging Python-based analytical tools to support fraud detection and risk management.

---

## 🎯 Objectives

* Analyze financial transaction data.
* Calculate and evaluate fraud rates.
* Compare fraudulent and non-fraudulent transactions.
* Identify transaction types with the highest fraud risk.
* Visualize fraud patterns using charts and graphs.
* Generate business insights and actionable recommendations.

## 📊 Analysis Performed

### 1. Data Exploration

* Dataset shape analysis
* Summary statistics
* Fraud rate calculation
* Transaction type analysis

### 2. Fraud Rate Analysis

Calculated the overall fraud percentage within the dataset to understand the prevalence of fraudulent transactions.

### 3. Transaction Amount Distribution

Used boxplots to compare transaction amounts between:

* Fraudulent Transactions
* Non-Fraudulent Transactions

This helps identify whether fraud is associated with higher-value transactions.

### 4. Fraud by Transaction Type

Analyzed fraud occurrence across different transaction categories such as:

* CASH_IN
* CASH_OUT
* PAYMENT
* TRANSFER
* DEBIT

Visualized fraud percentages using bar charts.

## 🔍 Key Findings

### High-Risk Transaction Types

Fraud is predominantly concentrated in:

* TRANSFER Transactions
* CASH_OUT Transactions

These transaction categories exhibit significantly higher fraud rates compared to others.

### Transaction Amount Patterns

Fraudulent transactions generally involve larger transaction amounts than legitimate transactions.

### Fraud Indicators

Important indicators associated with fraud include:

* Transaction Type
* Transaction Amount
* Account Balance Changes
